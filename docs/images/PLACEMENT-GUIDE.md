# Evidence placement

See the [evidence register](../evidence-register.md). Each selected original image is embedded once in the appropriate lab page. Instructional screenshots and duplicate views are excluded. From docs/labs, use ../images/filename.png; from the repository root use docs/images/filename.png.

PNG files must contain PNG bytes, not Base64 text or a link. New evidence should be checked for readability, action/outcome context and accurate captions before publication.
